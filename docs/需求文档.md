# ESP32-S3 智能开关 — 需求文档

## 项目概述

基于 ESP32-S3 开发板，开发一款可通过微信小程序远程控制的智能开关（继电器控制）。支持多用户使用、设备绑定与分享、定时任务、OTA 远程固件升级、操作日志查看。

---

## 功能清单

### 1. 用户管理
| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| U1 | 微信登录 | P0 | 小程序一键授权登录，获取用户信息 |
| U2 | 用户信息 | P1 | 显示昵称、头像 |

### 2. 设备管理
| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| D1 | 设备绑定 | P0 | 扫码或输入设备 ID，绑定到个人账户 |
| D2 | 设备列表 | P0 | 显示已绑定的所有设备 |
| D3 | 设备删除 | P1 | 解除设备绑定 |
| D4 | 设备重命名 | P2 | 修改设备显示名称 |

### 3. 设备控制
| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| C1 | 开关控制 | P0 | 远程控制继电器开/关 |
| C2 | 状态显示 | P0 | 实时显示设备在线/离线、开关状态 |
| C3 | 状态刷新 | P1 | 下拉刷新设备状态 |

### 4. 设备分享
| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| S1 | 生成分享链接 | P0 | 生成带设备 ID 的分享卡片 |
| S2 | 接受分享 | P0 | 好友点击链接后可控制该设备 |
| S3 | 分享管理 | P1 | 查看已分享的用户，可取消分享 |

### 5. 定时任务
| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| T1 | 创建定时 | P0 | 设置定时开/关（指定时间） |
| T2 | 重复定时 | P1 | 支持每天/每周重复 |
| T3 | 定时列表 | P0 | 查看设备的所有定时任务 |
| T4 | 删除定时 | P1 | 删除不需要的定时任务 |
| T5 | 启用/禁用 | P2 | 临时关闭某个定时任务 |

### 6. OTA 升级
| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| O1 | 固件版本显示 | P1 | 显示当前设备固件版本 |
| O2 | 推送升级 | P1 | 管理员可推送新固件到设备 |
| O3 | 升级进度 | P2 | 显示升级进度条 |

### 7. 操作日志
| 编号 | 功能 | 优先级 | 说明 |
|------|------|--------|------|
| L1 | 日志列表 | P1 | 按时间倒序显示操作记录 |
| L2 | 日志筛选 | P2 | 按设备、操作类型筛选 |
| L3 | 日志详情 | P1 | 显示谁、何时、做了什么 |

## 用户故事

### 场景 1：首次使用
> 作为新用户，我希望用微信一键登录，然后绑定我的智能开关，这样我就能远程控制它。

### 场景 2：日常控制
> 作为设备拥有者，我希望在小程序上点击开关按钮，这样就能远程开/关继电器。

### 场景 3：分享给家人
> 作为设备拥有者，我希望通过微信把设备分享给家人，这样他们也能控制这个开关。

### 场景 4：定时任务
> 作为用户，我希望设置每天晚上 10 点自动关灯，这样我就不用手动操作了。

### 场景 5：固件升级
> 作为设备拥有者，我希望远程推送固件更新，这样设备就能获得新功能。

---

## 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 控制指令响应时间 < 2 秒 |
| 并发 | 支持 100+ 设备同时在线 |
| 可用性 | 设备断线自动重连，云端 99% 可用 |
| 安全 | 微信授权登录，操作需鉴权 |
| 兼容 | 支持 iOS/Android 微信小程序 |

---

## 优先级说明

- **P0**：必须实现（MVP 最小可用产品）
- **P1**：应该实现（提升体验）
- **P2**：可以实现（锦上添花）
