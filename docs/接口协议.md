# ESP32-S3 智能开关 — 接口协议

## 概述

本文档定义了小程序 ↔ 云端、云端 ↔ 设备 之间的所有接口规范。

---

## 一、小程序 ↔ 云端（REST API）

### 通用规范

- 基础 URL: `https://your-domain.com/api`
- 请求格式: `application/json`
- 认证: `Authorization: Bearer {token}`
- 响应格式:

```json
{
  "code": 200,
  "message": "success",
  "data": {}
}
```

- 错误码: 200 成功, 400 参数错误, 401 未授权, 403 无权限, 404 不存在, 500 服务器错误

---

### 1. 用户登录

```
POST /api/login
```

**请求:**
```json
{
  "code": "wx_login_code"
}
```

**响应:**
```json
{
  "code": 200,
  "data": {
    "token": "jwt_token",
    "user": {
      "id": 1,
      "openid": "xxx",
      "nickname": "昵称",
      "avatar": "https://..."
    }
  }
}
```

---

### 2. 获取设备列表

```
GET /api/devices
```

**响应:**
```json
{
  "code": 200,
  "data": [
    {
      "id": 1,
      "device_id": "SW001",
      "name": "客厅灯",
      "gpio_pin": 42,
      "status": "on",
      "online": true,
      "firmware_version": "1.0.0",
      "created_at": "2026-10-20T10:00:00Z"
    }
  ]
}
```

---

### 3. 绑定设备

```
POST /api/devices/bind
```

**请求:**
```json
{
  "device_id": "SW001",
  "name": "客厅灯"
}
```

**响应:**
```json
{
  "code": 200,
  "message": "绑定成功",
  "data": { "id": 1, "device_id": "SW001" }
}
```

---

### 4. 控制设备

```
POST /api/devices/:id/control
```

**请求:**
```json
{
  "action": "on"
}
```

action 取值: `on` / `off`

**响应:**
```json
{
  "code": 200,
  "message": "指令已下发"
}
```

---

### 5. 分享设备

```
POST /api/devices/:id/share
```

**请求:**
```json
{
  "target_openid": "好友的openid"
}
```

**响应:**
```json
{
  "code": 200,
  "data": {
    "share_url": "pages/accept/index?device_id=SW001&token=xxx"
  }
}
```

---

### 7. 定时任务

```
POST   /api/schedules          # 创建
GET    /api/schedules?device_id=1  # 列表
PUT    /api/schedules/:id      # 修改
DELETE /api/schedules/:id      # 删除
```

**创建请求:**
```json
{
  "device_id": 1,
  "action": "on",
  "cron_expr": "0 22 * * *",
  "enabled": true
}
```

cron_expr 格式: `分 时 日 月 星期`

**响应:**
```json
{
  "code": 200,
  "data": {
    "id": 1,
    "device_id": 1,
    "action": "on",
    "cron_expr": "0 22 * * *",
    "enabled": true
  }
}
```

---


## 二、云端 ↔ 设备（巴法云 TCP）

### 设备端连接

```
连接: bemfa.com:8344
订阅: cmd=1&uid={uid}&topic={device_id}
心跳: ping\r\n         （每60秒）
心跳回应: pong\r\n
```

### 云端 → 设备 指令

**控制开关:**
```
cmd=2&uid={uid}&topic={device_id}&msg={"cmd":"set","action":"on"}
cmd=2&uid={uid}&topic={device_id}&msg={"cmd":"set","action":"off"}
```

**OTA 升级:**
```
cmd=2&uid={uid}&topic={device_id}&msg={"cmd":"ota","url":"https://...","version":"1.1.0"}
```

### 设备 → 云端 上报

**状态上报:**
```
cmd=2&uid={uid}&topic={device_id}&msg={"status":"on","gpio":42,"firmware":"1.0.0"}
```

**心跳上报:**
```
cmd=2&uid={uid}&topic={device_id}&msg={"type":"heartbeat"}
```
